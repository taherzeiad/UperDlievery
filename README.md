Aber Driver — Ride-Hailing Driver App (Android)

Built the driver-side Android app for Aber, a ride-hailing platform, using Kotlin, Jetpack Compose, and MVVM/Clean Architecture.

Designed and implemented a shared Compose UI kit (buttons, text styles, cells, dividers, segmented controls, message bars) reused consistently across the entire app to ensure a cohesive design language and faster feature delivery.

Key features implemented:
• Splash and onboarding flow (job acceptance, real-time tracking, earnings)
• Authentication — sign up, sign in, and phone verification
• Home screen with offline/online driver states
• Real-time trip requests with a swipe-up list and detailed booking view (fare breakdown, call/message/cancel actions)
• Turn-by-turn navigation to pickup locations
• In-app rider messaging with a custom chat UI

Tech stack: Kotlin, Jetpack Compose, MVVM, Coroutines/Flow, Coil 3 for image loading.
